# Create Bootstrap 386 page skeleton

Create Bootstrap 386 page skeleton

## Usage

``` r
page_386(..., title = NULL)
```

## Arguments

- ...:

  Slot for shiny386 layout elements.

- title:

  The browser window title (defaults to the host URL of the page). Can
  also be set as a side effect of the titlePanel() function.

## Value

A list of tags
