# Create a Bootstrap 386 progress bar

The progress bar may be updated server side. See
[update_progress_386](https://rinterface.github.io/shiny386/reference/update_progress_386.md).

## Usage

``` r
progress_386(id = NULL, value, status = NULL)
```

## Arguments

- id:

  Progress unique id.

- value:

  Progress value. Numeric between 0 and 100.

- status:

  Progress status.

## Value

A progress bar tag.
