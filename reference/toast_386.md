# Create a Bootstrap 386 toast

Display user feedback

## Usage

``` r
toast_386(id, title = NULL, subtitle = NULL, ..., img = NULL)
```

## Arguments

- id:

  Unique toast id.

- title:

  Toast title.

- subtitle:

  Toast subtitle.

- ...:

  Toast content.

- img:

  Toast image.

## Value

A toast
